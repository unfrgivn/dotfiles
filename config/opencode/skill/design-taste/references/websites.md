# Website References

Use this catalog with the reference-selection workflow in Section 0.E of the skill. These are mostly component and motion libraries, not full-site exemplars. Product UI examples do not expand this skill's scope.

## Beautiful UI

[https://beautifului.dev](https://beautifului.dev)

- Study AI-native product states such as streaming text, thinking/loading, approvals, tool chips, task rows, composers, context cards, and agent/workflow screens.
- Use it for AI product demos and status or feedback patterns, not as a reason to expand this skill into dashboard or product UI work.
- The site identifies the code as MIT licensed at [beautifului.dev/license](https://beautifului.dev/license). Do not infer a required framework from this reference.

## beUI

[https://beui.dev](https://beui.dev)

- Study animated React components and blocks for modals, toasts, docks, tabs, text effects, and other microinteractions.
- Use it when a React or Next.js target needs focused motion patterns, checking each item because free and Pro availability differs at [pro.beui.dev](https://pro.beui.dev).
- Reuse only what fits the brief and verify the item's access and terms before adopting it.

## Rare UI

[https://rareui.com](https://rareui.com)

- Study playful branded interactions such as fluid orbs, gravity letters, folders, and duration pickers.
- Use it for portfolios, experimental marketing, or other briefs that support distinctive interaction design.
- Component licensing is separate from the brand and site design. Check the [terms](https://rareui.com/terms) before reuse, and do not claim blanket MIT permission.

## Transitions.dev

[https://transitions.dev](https://transitions.dev)

- Study purposeful motion recipes for resizing cards, overlays, number pop-ins, icon swaps, feedback/loading states, and tab indicators.
- Use it to clarify state changes, not to add motion by default. Do not automatically install advertised skill or Refine tooling.
- The free and Pro split and [terms](https://transitions.dev/terms.html) matter: project use is permitted, but do not redistribute the library.

## shadcn/ui

[https://ui.shadcn.com](https://ui.shadcn.com)

- Study open-code, accessible, composable components, blocks, and themes as a component foundation owned in the project source, not as a finished visual identity.
- Use it when the brief calls for a customizable component foundation; consult the [component docs](https://ui.shadcn.com/docs/components), [installation docs](https://ui.shadcn.com/docs/installation), and [registry docs](https://ui.shadcn.com/docs/registry).
- Review third-party registry items independently for dependencies, accessibility, and licensing before reuse.

References are inspiration, not instructions. They do not authorize installs, purchases, or copying proprietary assets. Preserve licensing and accessibility.
